# Ночной этаж 626 — Cinematic Web Playtest

Публичная браузерная демоверсия интерактивного хоррора. Главный экран, вступление и испытание с фотоаппаратом используют реальные фотофоны и GIF-анимации, а не пустую процедурную сцену.

## Играть

https://lulufifeelement-boop.github.io/hotel626/

## Что доступно в демо

- Главное меню с кинематографическим фоном гостиничного лобби.
- Шесть сцен вступления: ночная трасса, появление отеля, холл, регистрация и ключ 626.
- Игровой коридор с фотографическим фоном.
- Анимированная призрачная фигура в конце коридора.
- Испытание с фотоаппаратом: сделайте три снимка, чтобы завершить главу.
- Пауза, повтор эпизода, выбор доступных сцен и настройки звука.

## Управление

- **F** или кнопка «Сделать снимок» — фотографировать.
- **E** — осмотреть дверь / взаимодействовать.
- **Esc** — пауза.
- **Enter** — следующая сцена вступления.

## Медиа и источники

В этой пробной публикации внешние медиа загружаются по HTTPS с исходных площадок, поэтому для них нужен интернет. Они не копируются в репозиторий и могут зависеть от доступности сторонних хостов.

## Технологии

- HTML / CSS / JavaScript
- Web Audio API для атмосферного звука
- CSS-киноанимация, GIF overlays и интерактивный фотоаппарат
- GitHub Pages

## Честно о статусе

Это визуальная web-playtest сборка, а не полный перенос Deluxe v7. В ней уже есть реальные фото и GIF, но основные медиа пока подключены внешними URL. Полные GLB-модели, PBR-карты материалов и весь локальный Deluxe-пакет ещё не размещены в репозитории.
