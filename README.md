# Ночной этаж 626 — Cinematic Web Playtest

Публичная браузерная демоверсия интерактивного хоррора. Вступление использует фотографии и GIF-вставки, а эпизод с горничной получил панорамное управление от первого лица.

## Играть

https://lulufifeelement-boop.github.io/hotel626/

## Управление в эпизоде с горничной

- Нажми **«Начать осмотр»** на обучающем экране.
- **Мышь** — оглядеться. На компьютере игра захватывает курсор; нажми Esc, чтобы открыть паузу.
- **W / A / S / D** — ходить вперёд, в стороны и назад.
- **Shift** — двигаться быстрее.
- **F** или кнопка «Сделать снимок» — фотографировать.
- **Esc** — пауза.

## Как пройти первое испытание

1. Оглянись мышью и найди горничную в коридоре.
2. Иди к ней клавишей W, пока расстояние не станет примерно 4–10 метров.
3. Поверни взгляд так, чтобы горничная оказалась прямо под центральным прицелом. При правильном наведении прицел подсветится.
4. Нажми F или кнопку фотографии. Снимок засчитывается только при верном наведении и дистанции.
5. После каждого снимка она отступает. Иди за ней и повтори ещё два раза.
6. Если она подойдёт слишком близко, отступай клавишей S.

На телефоне осмотр выполняется свайпом, перемещение — экранными стрелками внизу, фотографирование — кнопкой «Фото».

## Содержимое демо

- Кинематографическое вступление из шести сцен.
- Коридор с фотофоном и анимированным GIF-персонажем.
- Панорамное движение с изменением перспективы и параллаксом.
- Фотоиспытание с проверкой направления взгляда и дистанции.
- Пауза, повтор эпизода, настройки звука и сенсорное управление.

## Технологии и ограничения

- HTML / CSS / JavaScript
- Web Audio API
- Панорамная фотосцена с имитацией перемещения, а не полноценный свободный 3D-уровень с физической геометрией.
- Внешние изображения и GIF загружаются по HTTPS со сторонних хостов и требуют интернет-соединения.
