# Ночной этаж — Hotel 626

Браузерный хоррор-прототип. Это публичная **web playtest-сборка**, созданная для проверки игрового цикла и публикации через GitHub Pages.

## Запуск онлайн

После успешного деплоя GitHub Pages игра будет доступна по адресу:

https://lulufifeelement-boop.github.io/hotel626/

Первый запуск может занять несколько минут после включения GitHub Actions.

## Локальный запуск

Откройте репозиторий через локальный HTTP-сервер (например, VS Code Live Server) и перейдите на `http://localhost:5500`.

Не открывайте файл через `file://`: браузерные ES-модули Three.js требуют HTTP(S).

## Управление

- **W / A / S / D** — движение
- **Мышь** — осмотр
- **E** — взаимодействие
- **F** — фотографирование
- **G** — фонарь
- **Esc** — пауза / меню
- **R** — перезапуск эпизода

## Технологии

- Three.js 0.187.0 (WebGL)
- PointerLockControls
- Процедурные текстуры и геометрия
- Web Audio API для атмосферного звука
- GitHub Pages для публикации

## Важное примечание о сборке

Эта ветка содержит оптимизированную для публичного веб-просмотра процедурную playtest-сборку: основные игровые сцены и предметы формируются кодом в браузере, а Three.js загружается с CDN. Большой локальный арт-пакет Deluxe v7 (GIF, GLB и карты материалов) пока не включён в репозиторий; он остаётся отдельным архивом проекта. Поэтому онлайн-версия — самостоятельный облегчённый web-preview, а не полный перенос всех ресурсов Deluxe v7.

## Статус

Экспериментальная сборка. Проверяйте производительность и управление в актуальном Chrome или Edge. Для Pointer Lock требуется клик по игровому окну.
