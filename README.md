# Ночной этаж 626 — Deluxe 3D WebGL Playtest

Браузерный хоррор на Three.js. Это уже не панорама с имитацией перемещения: сцены строятся в настоящем 3D-пространстве, камера свободно поворачивается, игрок перемещается по комнатам, а интерактивные предметы определяются центральным лучом камеры.

## Играть

https://lulufifeelement-boop.github.io/hotel626/

После каждого обновления GitHub Pages может потребоваться немного времени, чтобы отдать новую версию. Для сброса кеша используйте Ctrl+F5.

## Управление на компьютере

- **W / A / S / D** — движение.
- **Мышь** — свободный обзор от первого лица. Первый клик по сцене захватывает курсор.
- **Shift** — бег.
- **E** — взаимодействие с дверями и предметами, на которые наведён прицел.
- **F** — фотоаппарат в испытании с горничной.
- **G** — фонарь.
- **Esc** — пауза, повтор сцены, выбор эпизода и настройки.

## Управление на телефоне

Используйте экранный D-pad для движения, правую часть игрового экрана — для поворота камеры, а кнопки действий — для взаимодействия и фотоаппарата.

## Пролог и игровая структура

- Шесть кинематографических сцен о ночной дороге, отеле и регистрации.
- Интерактивный трёхмерный холл с администратором, журналом и ключом 626.
- Десять отдельных испытаний: спальня, коридор, горничная, лестница, детская, зеркальная комната, кодовый замок, фотокомната, телефон и финал.
- Интерактивные двери, предметы, механизмы и головоломки.
- Горничная — объёмный процедурно скелетный персонаж с состояниями наблюдения, ходьбы, преследования, оглушения и атаки.
- Фотоиспытание засчитывает снимок только при наведении камеры на персонажа.
- Встроенный фонарь, атмосферная музыка, звуки шагов и эффекты.
- Пауза, повтор сцены, выбор эпизода, настройки чувствительности мыши и качества графики.

## Технологии

- Three.js 0.187.0 / WebGL.
- PointerLockControls для управления камерой.
- GLTFLoader для необязательных внешних GLB-моделей.
- PBR-материалы с процедурными картами цвета, рельефа, нормалей и шероховатости.
- SSAO / GTAO, Bloom, ACES Filmic Tone Mapping.
- GSAP для переходов интерфейса.
- Web Audio API для звукового оформления.

В текущей GitHub Pages сборке базовые 3D-модели и материалы строятся процедурно в браузере. Дополнительные локальные GLB-файлы не обязательны. Для загрузки Three.js и GSAP требуется интернет.

## Примечание о статусе

Это играбельный прототип, а не готовая коммерческая AAA-игра. В этой среде синтаксис JavaScript и статическую структуру можно проверить, но полноценное ручное прохождение в настоящем браузере здесь ограничено системным запретом на открытие локального игрового сервера. Поэтому просим сообщать о конкретных местах, где управление, коллизии или загадки ведут себя неправильно.
